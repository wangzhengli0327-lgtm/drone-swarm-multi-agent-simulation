# Security

## Secrets

Never commit API keys, `.env`, Streamlit secrets, exported reports containing credentials, or the local `API配置备忘录.txt`.

If a key has appeared in a file, chat transcript, screenshot, archive, or Git history, revoke and rotate it before publishing the repository. Deleting the visible line from a later commit is not sufficient because earlier Git history remains accessible.

## Scope

This repository is an abstract teaching simulation. Security reports should not include real operational coordinates, real platform control details, weaponization, target selection, or instructions for evading real defenses.
